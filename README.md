# Самостоятельные задания Java и OpenGL

В комплекте 33 задания с номерами из курса. Условия заданий 01, 16 и 28 отсутствуют.
Каждое решение находится в отдельном файле `TNN.java`; краткое описание написано
в начале файла. Изображения и карты находятся в `assets`, библиотеки JOGL — в `lib`.

## Запуск

Нужны JDK 8 и графическая среда Linux или WSLg. В терминале из папки `solutions`:

```bash
bash run.sh       # список заданий
bash run.sh T02   # пример растрового задания
bash run.sh T23   # пример OpenGL-задания
```

Каждое задание компилируется отдельно. Файлы классов создаются в `build`.

## Управление

- Растровые задания: ЛКМ показывает следующий шаг, `←` — предыдущий, `R` — исходное изображение.
- `T23`–`T27`, `T30`–`T35`: стрелки поворачивают объект или перемещают камеру.
- `T29`: ЛКМ и `→` — следующая операция, `←` — предыдущая, `R` — первая. Название и результат операции показаны в окне.
- `T36`: ЛКМ выбирает точку на карте, стрелки перемещают её; координаты и высота показаны под картой.

Для другой карты высот передайте `T36` путь к файлу:

```bash
bash run.sh T36 /path/to/H.txt
```
