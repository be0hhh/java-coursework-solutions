# Java и OpenGL: учебные задания

В папке — 33 самостоятельных задания `TNN.java`. Условия `T01`, `T16` и `T28` отсутствуют.

## Запуск

Нужны JDK 8 и графическая среда Linux x86_64 или WSLg. Из этой папки:

```bash
bash run.sh       # список заданий
bash run.sh T02   # запуск задания 2
bash run.sh T23   # запуск задания OpenGL
```

Каждая команда компилирует только выбранное задание. Ресурсы и библиотеки JOGL находятся в `assets` и `lib`.
Для Windows нужны подходящие нативные библиотеки JOGL вместо Linux JAR из `lib`.

## Управление

- `T02`–`T18` (имеющиеся): `Space` — переключить исходник и полный результат; ЛКМ — увеличить долю результата на 10%; `←` — уменьшить её на 10%; `R` — исходник. Подпись показывает текущий режим.
- `T19`–`T22`: результат рисования показан сразу, управления нет.
- `T23`: `↑`/`↓` вращают по X, `←`/`→` — по Y.
- `T24`–`T27`: `↑`/`↓` вращают по X, `←`/`→` — по Z.
- `T29`: ЛКМ или `→` — следующая операция, `←` — предыдущая, `R` — первая.
- `T30`: `←`/`→` вращают дом по Z.
- `T31`: `↑`/`↓` вращают конфету по X, `←`/`→` — по Z.
- `T32`: `←`/`→` вращают снеговика по Z.
- `T33`: `W`/`S` — движение вперёд/назад; `A`/`D` — поворот направления взгляда; `Q`/`E` — крен; `↑`/`↓` — наклон камеры; `R` — сброс.
- `T34`: `↑`/`↓` вращают ландшафт по X, `←`/`→` — по Z.
- `T35`: `←`/`→` вращают куб по горизонтали, `↑`/`↓` — по вертикали.
- `T36`: ЛКМ выбирает точку на карте, стрелки перемещают её; под картой показаны координаты и высота.

## Как объяснять код на защите

Начинай с входных данных, затем объясни алгоритм и покажи результат. После этого расскажи про окно и управление.
В каждом файле есть короткие комментарии к основному алгоритму. Описание ниже соответствует реализации;
для сверки с формулировками преподавателя нужны исходные условия.

### Общая структура

- `T02`–`T18`: `main` загружает картинку, `process` вычисляет результат, `show` создаёт окно.
  `ImagePanel` хранит исходник, результат и шаг смешивания. Обработка выполняется один раз;
  клики меняют долю уже вычисленного результата, а не применяют фильтр повторно.
- `T19`–`T22`: `render` создаёт готовое изображение, `paintComponent` показывает его в окне.
  Точки кривых соединяются отрезками Брезенхема, чтобы между ними не было разрывов.
- В OpenGL сначала расположены методы построения фигур, затем `init`, `display`, `reshape`,
  `dispose`, управление и запуск. `init` настраивает контекст, `display` рисует кадр,
  `reshape` обновляет перспективу при изменении размера окна. Клавиши меняют состояние и вызывают `repaint`.
- `T29`: классы `Vector3` и `Matrix3x3` выполняют вычисления, окно показывает примеры операций.
- `T36`: загрузка сетки и `getZ` вычисляют высоту, панель карты отвечает за выбор точки и отображение.

### Формулы, которые стоит понимать

**RGB.** `getRGB` возвращает упакованный цвет. `(rgb >> 16) & 255` извлекает красный,
`(rgb >> 8) & 255` — зелёный, `rgb & 255` — синий. `(red << 16) | (green << 8) | blue`
собирает цвет обратно. Для этих заданий используется `TYPE_INT_RGB`, без прозрачности.

**Смешивание.** Один канал вычисляется как
`((10 - step) * sourceChannel + step * resultChannel + 5) / 10`.
При `step = 0` получаем исходник, при `step = 10` — результат. `+5` округляет до ближайшего целого.
В T15 пространственный переход между летом и зимой вычисляется внутри `process`;
общее управление окном дополнительно смешивает исходник с этим готовым переходом.

**Безье.** `B(t) = (1-t)³P0 + 3t(1-t)²P1 + 3t²(1-t)P2 + t³P3`, где `0 ≤ t ≤ 1`.
Первая и последняя точки — концы кривой, две средние управляют её формой.

**Повороты и камера.** `glPushMatrix` и `glPopMatrix` сохраняют и восстанавливают преобразования,
чтобы размещение одной детали не влияло на следующую. В T29 угол матрицы поворота задан в радианах,
а в T33 и `glRotated` — в градусах. При наклоне камеры направление и верх поворачиваются вместе.

**Высота.** В T36 целые части координат определяют ячейку, дробные — положение внутри неё.
Чётность суммы координат ячейки задаёт диагональ. Веса трёх вершин выбранного треугольника
в сумме равны 1; на вершине получаем ровно её высоту.
